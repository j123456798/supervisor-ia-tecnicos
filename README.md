# Supervisor IA de Técnicos

Sistema básico de automatización usando Paperclip.

## Funciones
- Registro técnico
- Supervisión IA
- Detección de ausencias
- Alertas automáticas

## Flujo

Técnico → Formulario → IA Supervisor → Reporte

## Tecnologías
- Paperclip
- GitHub
- Google Forms
- Google Sheets
